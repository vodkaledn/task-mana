Sync across devices

Task Deck stores your tasks in this browser only. To share them with another device it keeps a copy in a secret GitHub Gist — visible to nobody but you, and only to someone holding the link. Set the same token up on each device and they merge, task by task.

  1. Open github.com/settings/tokens → Tokens (classic) → Generate new token (classic).
  2. Tick only the gist scope. Give it a long expiry. Generate and copy it. It must be a classic token starting ghp_ — fine-grained tokens cannot use gists.
  3. Paste it below and press Save & sync. On your second device, paste the same token and the Gist ID shown here afterwards.
